Proposed design contract

Material, with a personality

Semantic color roles, tonal surface elevation, 24–28px card corners, pill-shaped actions, segmented controls, clear selected states, modal sheets, dialogs and snackbars. No decorative glass or tiny icon-only actions.

Primary: navigation and actions

Accent: atmosphere, not status

Error: explicit failures only

One shared theme

Proposed spacing: 4, 8, 12, 16, 24, 32. Type roles: display 32/40, title 22/28, body 16/24, label 14/20. Use system-friendly sans-serif; the browser preview uses Segoe UI.

48dp minimum interactive targets, scalable text, named color swatches, non-color status cues, keyboard focus and screen-reader labels. Avoid fixed screen heights in the real app.

Respect reduced motion; optional short transitions only. No endless decorative animation. Final native contrast, font scaling and screen-reader behavior must be checked during implementation.

Behavior preserved

Local-only groups and timelines; existing lamp capabilities and presets; built-in continuous sequences; custom timeline duration and timing rules; audio import, built-in sound samples, clip timing and volume; preview restoration; optional Home restoration; rename and forget flows.

Proposed UX changes requiring agreement: bottom navigation, visible Home target selection, library/editor separation, connection entry point, and destructive confirmations.

Decisions still open

Palette and light/dark scope. How atmospheric versus utilitarian it should feel. Whether the Home should remain a single large Run button. Bottom navigation versus the current drawer.

No component library selected or installed. React Native Paper is a candidate for Material 3 primitives, not an approved dependency. Palette approval is not implementation approval.
